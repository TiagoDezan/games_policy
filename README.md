Políticas de privacidade dos jogos publicados na App Store, servidas pelo GitHub Pages.

| Jogo | Página |
|---|---|
| Zero Absoluto (Absolute Zero / Cero Absoluto / Zero Assoluto) | https://tiagodezan.github.io/games_policy/zero-absoluto/ |
| Block Quest | https://tiagodezan.github.io/games_policy/block-quest/ |
| Cesta (app) | Suporte: https://tiagodezan.github.io/games_policy/cesta/ · Privacidade: https://tiagodezan.github.io/games_policy/cesta/privacidad.html |

## Novo jogo
Crie uma pasta `<nome-do-jogo>/` com um `index.html` (e os `.md` por idioma, se quiser) e adicione o link em `index.html`.
